# mod-11 障壁の強化：旧座標体では強制同色対も存在しない

作成日：2026-09-16。対象リポジトリ：HeliCorgi/hadwiger-nelson-lab。
読んだ main のコミット：`3a1e42eab803cb17c49fd7c5cd4410e4feca8350`。

**位置付け：6色以上を必要とする平面単位距離グラフを構成したものではない。**
既存の Madore の彩色表と付値による還元を用い、リポジトリで未除外だった
旧座標体内の目標Bを排除する補題を導く。文献上の新規性は主張しない。
有限部分は添付プログラムで厳密検証した。以下の一般補題と付値の論証は
数学的証明であり、Leanなどによる形式検証や第三者査読はまだ行っていない。

## 1. 主張と量化の順序

実数体の部分体を

\[
 E=\mathbb Q(\sqrt3,\sqrt5,\sqrt{11})
\]

とし、距離1の点対を辺とするグラフを \(\Gamma(E^2)\) とする。
任意の異なる点 \(a,b\in E^2\) に対して、次を満たす彩色が存在する。

\[
 \exists c:E^2\to\{0,1,2,3,4\},\qquad
 c\text{ は適正彩色},\quad c(a)\ne c(b).
\]

従って、E内のどんな有限単位距離グラフにも、全適正5彩色で必ず同色になる
異なる2点は存在しない。必要色数を6以上にする目標Aがこの体で不可能である
という既存の障壁に加えて、強制同色対の目標Bもこの体では不可能となる。

重要なのは「任意の点対ごとに、その対を分離する彩色が存在する」という
量化である。全点対を一つの5彩色で同時に分離する、と主張しているのではない。

## 2. より一般的なグラフ補題

\(F=\Gamma(\mathbb F_{11}^2)\) と置く。Fの隣接条件は

\[
 (x-x')^2+(y-y')^2=1\pmod {11}
\]

である。ループを持たないグラフGからFへのグラフ準同型
\(h:V(G)\to\mathbb F_{11}^2\) が存在するなら、Gの任意の異なる2頂点は
適正5彩色によって分離できる。Gは有限である必要がない。

この補題の対象は「旧座標体のグラフ」より広い。混合体で構成した有限グラフ
でも、全辺を保存するFへの写像が別途見つかれば、この排除法が適用できる。
写像が見つからないことは、非5彩色可能性や強制同色の証明にはならない。

## 3. 彩色表の二つの追加性質

Madoreの補題4.5の11×11表をTとする。添付スクリプトに全121値を保存した。
行・列は0から数え、いずれも11を法として扱う。この表がFの全726辺で
適正な5彩色になっていることを、全点対から辺を再生成して検証した。

### 3.1 一点だけを塗り替えられる場所

\[
 T(0,0)=3.
\]

(0,0)の12近傍は

\[
 (0,\pm1),(\pm1,0),(\pm3,\pm5),(\pm5,\pm3)
\]

である。符号は独立で、すべてmod 11で解釈する。表を読むと、これらの
近傍で使われている色の集合はちょうど

\[
 \{0,1,4\}
\]

である。したがって(0,0)の色を3から2に替えても辺の衝突は起きない。

ここで利用するのは、還元先の表の一点を一括して変えることではない。
後で必要なときに、**G側の実際の一頂点だけ**を変える。

### 3.2 非零の平行移動周期がない

表Tの色別頂点数は

\[
 (|T^{-1}(0)|,\ldots,|T^{-1}(4)|)=(23,24,26,24,24).
\]

任意の \(0\ne d\in\mathbb F_{11}^2\) による平行移動の軌道は、すべて
11点からなる。もし \(T(s)=T(s+d)\) がすべてのsで成り立つなら、各色の
集合は11点軌道の和集合になり、その大きさは11の倍数でなければならない。
しかし色0は23点なので矛盾する。

従って、各非零dに対し

\[
 \exists s\in\mathbb F_{11}^2:\quad T(s)\ne T(s+d).
\]

これは計算に頼らない短い論証である。プログラムでは加えて全120非零dを
走査し、それぞれに対する具体的なsも保存した。

## 4. 一般補題の証明

異なる頂点a,bを固定する。

### 場合1：h(a)とh(b)が異なる

\(d=h(b)-h(a)\ne0\) とする。3.2より、\(T(s)\ne T(s+d)\) となるsを選べる。
全頂点vの色を

\[
 c(v)=T(h(v)-h(a)+s)
\]

で定める。平行移動はFの隣接を保存し、hも辺を保存するので、cは適正な
5彩色である。a,bの色はそれぞれT(s),T(s+d)で、異なる。

### 場合2：h(a)=h(b)

まず

\[
 c_0(v)=T(h(v)-h(a))
\]

で塗る。a,bはいずれも色3になる。aに隣接する頂点の像は、正規化後に
Fの(0,0)の近傍に属するので、その色は0,1,4のどれかである。

ここでa**だけ**の色を2に替える。他の頂点は変えない。aに接する辺は
衝突せず、aに接しない辺は変更の影響を受けない。bはaとは異なる実際の
頂点なので色3のまま残り、求める分離彩色が得られる。証明終。

なお、同じ像を持つ頂点どうしに辺があることはない。辺があればFの一点に
ループが必要となり、準同型の仮定に反する。

## 5. なぜE全体からFへの準同型が存在するか

この部分はMadoreの命題3.2／系3.4の還元法と、リポジトリの既存の
`ARITHMETIC_BARRIER.md` の議論を用いる。

mod 11で

\[
 5^2=3,\qquad4^2=5,
\]

かつ両根は単純根なので、Henselの補題でそれぞれ \(\mathbb Q_{11}\) の
平方根へ持ち上がる。\(\sqrt{11}\) を加えると

\[
 E\hookrightarrow L=\mathbb Q_{11}(\sqrt{11})
\]

という体の埋め込みを得る。\(X^2-11\) は11でEisensteinなので、この拡大は
全分岐で、剰余体は \(\mathbb F_{11}\) のままである。この付値をEに制限し、
付値環をO、極大イデアルをmとする。\(O/m=\mathbb F_{11}\) である。

### 単位ベクトルの座標はOに入る

\(x^2+y^2=1\) で、例えば \(v(x)\le v(y)\) かつ \(v(x)<0\) と仮定する。
xで割ると

\[
 1+(y/x)^2=1/x^2.
\]

左辺の各項はOに入り、右辺はmに入る。還元すると
\(1+\overline{y/x}^{\,2}=0\) となるが、-1は \(\mathbb F_{11}\) の平方ではない。
これは矛盾である。yの付値が最小のときも同じ。従ってx,yともOに属する。

### 剰余類ごとに平行移動して還元する

上の事実により、\(\Gamma(E^2)\) の各辺の両端は、同じ \(E^2/O^2\) の
剰余類に入る。各剰余類Cの代表r_Cを選び、その類の点pに

\[
 h(p)=\overline{p-r_C}\in\mathbb F_{11}^2
\]

を対応させる。辺の差は正しく還元され、距離の二乗が1という方程式を保つ。
従ってhは求めるグラフ準同型である。4節を適用すれば1節の主張を得る。

**EからF_11への体準同型があると主張してはいけない。** そのような写像は
標数の違いから存在しない。使っているのは付値剰余類ごとの平行移動と、
付値環上の還元であり、全体ではグラフ準同型である。

## 6. Gen2成果物での具体的検証

入力はActions run `34957362184` のartifact `10391403066` の `GRAPH.json`。
点とソート済み辺のsemantic SHA-256は

`b46ea400f8b8fdd536916aa7b1dbc5eadc7658fa269186091a9fdb90e32f559f`

で、既存の障壁記録と一致した。

| 項目 | 今回の結果 |
|---|---:|
| 相異なる厳密座標の点 | 12,102 |
| 保存辺の厳密な単位距離検査 | 80,678 / 80,678 |
| 使用される剰余点 | 121 |
| 点対分離に使う適正5彩色の族 | 875個 |
| 全辺検査の総数 | 70,593,250 |
| 875彩色の色列がすべて異なる頂点 | 12,102 / 12,102 |
| この彩色族が分離する相異なる点対 | 73,223,151対すべて |

875彩色は、剰余点を区別する7個の平行移動彩色と、同一剰余点のファイバー内を
区別する868個の二進符号による塗り替え彩色からなる。各ファイバーは独立集合で、
対応する平行移動で色3を色2へ自由に替えられるため、任意の部分集合を替えられる。
ファイバー内の頂点番号に二進符号を割り当てれば、対ごとのSAT探索なしに全点対を
分離する有限の彩色族を構成できる。再生成レシピをJSONに保存した。

「全点対を分離」は、対ごとに875彩色のうち少なくとも一つで色が違うという意味。
一つの彩色で12,102種類の色を使うという意味ではない。

具体例として、0始まりの頂点7と12は両方とも剰余が(4,10)である。
(7,1)だけ表を平行移動した後、頂点7だけを色2へ替えると、
頂点7・12はそれぞれ色2・3になり、80,678保存辺すべてで衝突がない。
この全頂点彩色も添付した。

計算は標準Pythonのみで、SATソルバーや浮動小数点を使っていない。
保存されていない本当の単位辺についても、座標の環への所属を確認したうえでの
還元の一般論が適用される。保存辺の全対生成を行ったと主張しているわけではない。

## 7. 追加の有限チェック

Fの各頂点を二つずつに複製し、元の各辺を両ファイバー間の全4辺に置き換えた
242頂点・2,904辺のグラフについても、363個の適正5彩色を全辺検査し、
全29,161点対が分離されることを確認した。

不正な単位辺、同一点の重複、11で割る直接還元、異なる座標体の入力などを
拒否する回帰テスト10件も通過した。

## 8. 何が未解決のままか

この結果は任意の実座標のグラフには適用できない。七回対称のG3や
Q(zeta210)を用いる混合体の最新8,520頂点グラフを、この証明だけで
新たに排除したわけではない。今回それらのSAT結果の再実行はしていない。

今回閉じたのは、旧E内のAだけでなくBも含む探索である。6色以上の有限配置、
5色でのphi端点不等色強制部品、平面の6彩色のどれも、この結果からは得られない。
