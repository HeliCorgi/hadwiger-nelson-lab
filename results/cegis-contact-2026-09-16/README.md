# Exact-contact CEGIS: publication and checkpoint continuation

2026-09-16. **No new Hadwiger-Nelson bound or improved discovery rate is claimed.**
This is the proposed counterexample-guided prototype, not a six-chromatic graph.
The prior local bundle has been repackaged into source code, transparent replay
recipes and publication hashes rather than duplicating large intermediate graphs.

## Implemented logic and limitations

The source module is moved by exact rotations using
`q=(5+sqrt(-11))/6`, q or its conjugate, and sixth-root rotations about 0 or 1.
All actual point coincidences are merged and all exact unit-distance edges are
included. Arithmetic is Q(zeta210,sqrt(-11)); adding the new quadratic component
is not proof of escaping every possible five-colorability obstruction.

Every candidate is tested against saved parent colorings. A directly validated
color-permutation extension is positive evidence. Otherwise fixed-parent SAT
queries are attempted. Only an independently checked negative can score a fixed
coloring as blocked. Fixed-color UNSAT never implies ordinary non-colorability.
The selected candidate is recolored with all old colors free; only one center
color is symmetry-fixed. UNKNOWN and unverified negatives never score.

The guided arm uses certified fixed-color blocks, then contact count and smaller
size as heuristic tie-breaks. The random arm uses the same configured candidate
and query limits, not guaranteed identical CPU time. A small fixed proposal
grammar, partial color-bank coverage, and solver timeouts limit the experiment.

A checked free negative is followed by a center-deleted coloring query and an
independent geometry audit. No new bound is announced automatically. Glucose4
negatives require strict DRAT verification. The <=9-point exhaustive backend is
only a local calibration oracle; external solvers are positive-witness-only.

## Publication fixes and checks

The interface counter now includes shared old vertices, not only endpoints of
new cross edges. This repairs a potentially over-aggressive one-contact screen.
A regression test covers coincident copies with three shared vertices and no new
cross edges. All 29 tests passed locally. Previously evaluated graph hashes are
now preserved across resumed rounds instead of silently resetting the seen set.
These changes do not alter any restored graph or its stored coloring.

`PUBLISH_MANIFEST.json` binds the published implementation and replay inputs to
the local bytes. `hn_cegis_verify.py` independently generates Phi210 with SymPy
and audits all point pairs using separate integer-ring arithmetic and residue
primes. It does not import the search arithmetic or a SAT solver, and does not
claim to check UNSAT traces itself.

## Workflow

`hn-cegis-contact` runs on relevant PR changes or manual dispatch, with contents
read-only, pinned actions/dependencies, no scheduled polling and no repository
writes. A 7-point/11-edge Moser-spindle control must pass Glucose4/DRAT and exact
geometry checks before production starts. Source G3 is rebuilt and hash-checked.
Four production arms (seeds 11/29, guided/random) restore the exact old states and
continue at round index 2, not from an empty run. Each gets two additional rounds,
three candidates per round, fixed queries <=3 seconds, free queries <=30 seconds,
and <=9,000 vertices. Maximum parallelism is 2; jobs have a 10-minute wall cap
and calibration a 5-minute cap. These are resource bounds, not mathematical claims.

All available graphs, CNFs, proofs, positive witnesses, restore records and
checkpoints are uploaded as 90-day artifacts. A job completing successfully means
its bounded experiment and checks completed, not a mathematical discovery.
Remote outcomes must be read from that run; this README does not predeclare them.

## Reproduction

```sh
python -m pip install numpy==1.26.4 sympy==1.14.0 python-sat==1.9.dev7
PYTHONPATH=tools python -m unittest discover -s tools -p test_hn_cegis.py -v
python tools/hn_heptagon_exact.py --paths data/haugland-2608.04542v2-paths.txt --out-dir /tmp/input
python tools/hn_cegis_restore.py --source /tmp/input/G3.json --case 11-guided --out /tmp/resume
python tools/hn_cegis_contact.py --resume /tmp/resume --seed 11 --mode guided \
  --checker /path/to/drat-trim --out /tmp/continued
python tools/hn_cegis_verify.py --run /tmp/continued
```

Checkpoint continuation stores graph/color-bank state, not suspended SAT solver
learned clauses. Old reflection/translation studies and periodic-extension local
artifacts are separate and are not overwritten by this implementation.
